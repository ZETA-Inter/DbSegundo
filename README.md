
# BANCO DE DADOS - ZETA

ZETA é um aplicativo desenvolvido para auxiliar produtores rurais na criação de animais, oferecendo treinamentos e conteúdos técnicos e práticos que promovem o aprimoramento de seus conhecimentos.

Este repositório há vários scripts do banco de dados PostgreSQL. Deve ser executado pela ordem crescente da numeração do script.

## Linguagens utilizadas
Para o desenvolvimento dos scripts foi utilizado o PL/pgSQL.

## Estrutura dos arquivos
Os arquivos estão numerados. Para replicar o banco, deve-se executar os scripts de forma crescente - em relação a numeração de cada arquivo.


## Configuração Inicial
1. Clone o repositório:
```bash
git clone https://github.com/ZETA-Inter/DbSegundo.git
```
2. Abra os arquivos em alguma ferramenta de gerenciamento de banco de dados (recomenda-se a utilização do PgAdmin, pela utilização do PostgreSQL);
3. Execute cada script de forma sequencial.
